# 🐈 MayMayHome 使用說明書

歡迎使用 **MayMayHome 家庭中控台**！這份說明書整理了手機安裝、推播設定、通知中心、公費結算、居家設備與帳號管理的操作方式，隨時都能在離線狀態下查閱。

---

## 1. 加入主畫面（像 App 一樣秒開）

為了獲得全螢幕操作體驗並正常接收手機即時推播，建議將網站加入手機桌面：

### iPhone（請務必使用 Safari）
1. 使用 **Safari** 開啟 MayMayHome 網址。
2. 點擊畫面底部正中央的 **「分享」圖示**（方框＋向上箭頭）。
3. 往下滑選擇 **「加入主畫面」**，再點右上角 **「新增」**。
4. 之後請**一律從桌面的貓咪圖示開啟**，不要直接從 Safari 網址列進入。

### Android（建議使用 Chrome）
1. 使用 **Chrome** 開啟 MayMayHome 網址。
2. 點擊右上角 **「⋮」選單**，選擇 **「新增至主畫面」** 或 **「安裝應用程式」**。
3. 從手機桌面的貓咪圖示開啟即可。

> **Android 省電小提醒**：小米、OPPO、vivo、三星等手機若偶爾延遲收到通知，請到手機「設定 → 應用程式 → Chrome → 電池」改為「無限制」。

## 2. 頂部標題列與「三態推播鈴鐺」開關

畫面最上方標題列右側常駐兩個快捷圖示：**推播鈴鐺**與 **`[i]` 使用說明**。

| 鈴鐺圖示狀態 | 代表意義 | 點擊後的動作 |
| :--- | :--- | :--- |
| **灰色鈴鐺** | 尚未訂閱推播通知 | 引導完成「加入主畫面」並請求手機推播權限 |
| **綠色鈴鐺** | 已訂閱且手機推播開啟中 | 點一下可**暫停手機推播**（不影響 App 內通知中心收訊） |
| **紅色斜線鈴鐺** | 已訂閱，但手機推播已暫停或被系統封鎖 | 若為 App 內暫停，點一下即恢復開啟；若被手機系統關閉，會跳出系統設定指引 |

* 若您曾在手機「設定 → 通知」手動關閉 MayMayHome 權限，回到 App 時鈴鐺會**自動同步轉為紅色斜線**，方便隨時確認。
* 即使暫停手機推播，所有公告、換瓦斯與帳務提醒仍會即時送達首頁右下角的 **「通知中心」**。

## 3. 首頁貓咪「通知中心」與家庭公告

首頁右下角常駐專屬的 **MayMay 貓咪小管家**，點擊貓咪或頭頂對話泡泡即可展開 **通知中心**：

* **無未讀通知**：貓咪會悠閒坐著發呆、偶爾眨眼或輕搖尾巴。
* **有未讀通知**：頭頂浮出白色對話泡泡提示未讀則數，貓咪會揮手提醒您查看。
* **整合雙類訊息**：
  * **📢 家庭公告**：全體成員皆可點右上角 **「＋ 發布公告」** 張貼家務消息，並顯示已讀名單與人數；點擊公告可立即標記「已讀」。您可編輯或封存自己發布的公告。
  * **🔔 系統通知**：自動收納換瓦斯警示、瓦斯補滿、大額公費新增、每月結算與對帳確認，點擊通知可直接跳轉對應頁面。
* **快速整理**：可使用頂部的 **「✓ 全部已讀」** 與 **「🗑️ 清除已讀」** 保持通知清單整潔。

## 4. 公費結算中心

切換至 **「💰 公費」** 分頁可查看當月與歷史月份的房租、公費與電費明細：

* **成員本月結算明細**：清楚列出每個人的房租、公費分擔、電費分擔、代墊扣除與最終應繳（或應退／應收）金額，並顯示對帳狀態燈號。
* **新增支出代墊**：點擊 **「＋ 新增支出」**，從常用下拉選單選擇項目（或選「自訂項目」並勾選加入常用選單），填入金額與代墊人即可自動扣除您的應繳額度。
* **分攤規則**：
  * **一般公費**：依各成員當月「公費天數」比例分攤。
  * **電費**：依各成員當月「電費天數」比例獨立分攤。
* **編輯與刪除**：一般成員可修改或刪除自己建立的支出項目。

## 5. 居家設備與耗材（瓦斯與 HomeKit）

### 🔥 雙桶瓦斯追蹤
1. **換上第 2 桶時必按**：第 1 桶用完並手動切換至備用桶後，請於首頁或居家設備頁點擊 **「⚠️ 我已手動切換至第 2 桶」**，系統會記錄換桶人與時間，並立刻推播提醒全員叫瓦斯。
2. **新瓦斯送達時**：點擊 **「✅ 新瓦斯已送達（補滿 2 桶）」**，可順手勾選 **「同步計入本月公費支出」** 一次完成記帳，系統也會自動累積計算單桶平均使用天數。

### 💡 HomeKit 智慧燈泡庫
* 支援依空間篩選與關鍵字搜尋，卡片內提供 **「📋 複製」** 一鍵複製 8 碼或 11 碼配對碼，方便故障重置時直接貼上 Apple 家庭 App。
* 燈泡故障換新時，點 **「🔄 紀錄換新燈泡」**，系統會自動結算舊燈泡服役天數並歸檔至歷史紀錄。

## 6. 個人帳號與刪除申請

前往 **「⚙️ 設定」** 可管理您的個人帳號：

* **變更密碼**：輸入舊密碼與至少 4 碼新密碼即可即時更新；若忘記密碼，請告知管理員於後台一鍵重設 4 碼臨時密碼。
* **申請刪除帳號**：若未來搬離且所有帳務已結清，可點擊 **「🗑️ 申請刪除帳號」** 送出請求並通知管理員審核；在管理員審核前可隨時撤回申請。審核完成後系統將推播通知結果。

## 7. 管理員專屬操作指南（Admin）

以下功能僅管理員（Admin）可見與操作，皆集中於 **「💰 公費」** 與 **「⚙️ 設定」** 分頁：

### 🏠 總房租與房間比例連動
* 在 **「設定 → 總房租與房間比例」** 修改整戶總房租或各房權重（如 `36 : 21 : 17`），畫面會即時試算每間房月租與同房啟用人數對分金額。
* 若當月帳單全員仍處於「未結算」狀態，可勾選同步更新該月帳單房租。

### 👥 成員三段帳號狀態與跨月電費處理
* **啟用**：正常登入，計入同房房租對分與公費分擔。
* **待結電費（唯讀）**：適用於已搬離、但需等下期台電帳單結清的室友；開立新月份時會自動帶入房租 0 元與公費天數 0，僅需填入該期電費天數即可精準結算尾款。
* **停用**：撤銷登入權限並移出新月份開帳名單，但完整保留歷史帳單名稱。

### 🗑️ 帳號刪除審核與主動移除
* **審核成員申請**：有待審核申請時，**「設定 → 成員與帳號連動」** 頂部會顯示提醒橫幅；審核視窗會自動檢查對方是否仍有「待繳款／待退款」未結清帳目作為防呆提醒。
* **核准或主動刪除**：皆可編輯專屬的**感謝詞**，按下確認後系統會**先發送感謝詞推播給對方，再永久移除帳號**（歷史公費與結算紀錄上的姓名仍會完整保留，不影響過去帳務）。
* **駁回申請**：可填寫說明並駁回，對方會收到推播與通知中心提醒。

### 📊 每月開帳、固定模板與結算推播
1. **開立新月份**：至公費頁點擊 **「＋ 開立新月份」**，可一鍵勾選匯入「固定支出模板」（如網路費、管理費）。
2. **調整天數與房租**：點各成員列旁的編輯按鈕，即可微調當月自訂房租、公費天數或電費天數並即時重算全體金額。
3. **發送結算與對帳**：月底確認帳目無誤後，點 **「📊 結算並推播全員」** 鎖定帳期狀態並通知大家；收到轉帳後切換成員狀態為 **「已繳清」**，系統會自動私訊推播確認收款。對尚未繳款的成員也可點 **「⏰ 提醒」** 發送個別催繳通知。

### 📦 封存公告與系統設定
* 封存後的公告可在 **「設定 → 封存公告」** 隨時查閱或一鍵還原至通知中心。
* 在 **「設定 → 推播與排程」** 可維護網站公開網址（供推播點擊跳轉）與新增公告／支出的預設推播勾選狀態。
